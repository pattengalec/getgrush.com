Grush · Configurator

Every deployment starts here. This part isn't built yet.

This will be the tool that turns a filled-in form into a new deployment's config file and starting database — instead of writing both by hand each time.

What it will do

  • Collect a new deployment's identity — name, short site code, domain — and its business-specific fields for the six shared tables.
  • Generate a ready-to-drop-in config file, matching the shape every deployment already uses.
  • Generate the SQL that creates that deployment's table set, prefixed with its site code, sitting beside every other deployment in the same database.
  • Leave the one hand-designed piece — the catalog table for whatever that business actually works with — as a deliberate, separate step. Not automated, because it shouldn't be.
